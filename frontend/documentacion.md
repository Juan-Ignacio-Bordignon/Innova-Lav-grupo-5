# Documentación para ejecutar el Frontend

## 1. Clonar el repositorio

Primero clonar el repositorio desde GitHub:

```bash
git clone -b Frontend https://github.com/Juan-Ignacio-Bordignon/Innova-Lav-grupo-5.git


2. Entrar a la carpeta del proyecto

Una vez clonado el repositorio, entrar a la carpeta del frontend:

cd Innova-Lav-grupo-5
cd frontend


3. Actualizar la rama

Antes de ejecutar el proyecto, traer los últimos cambios:

git pull


4. Instalar dependencias

Si es la primera vez que se ejecuta el proyecto, instalar las dependencias:

npm install


5. Ejecutar la app

Para levantar el proyecto:

npm start


6. Abrir en el navegador

Una vez iniciado el proyecto, abrir en el navegador:

http://localhost:8081  (Por defecto)

Esperar unos segundos a que la app termine de buildearse.

Resumen de comandos
